# 🎮 坦克大战 (Tank Battle)

一个经典的 HTML5 Canvas 坦克大战游戏，纯前端实现，打开即玩。

## 🎯 游戏特色

- **经典玩法**：致敬经典 FC 坦克大战
- **多个关卡**：3 个精心设计的地图，随关卡循环并增加难度
- **多种地形**：砖墙（可摧毁）、钢铁（不可摧毁）、水域（不可通行）、草丛（视野遮挡）
- **敌人 AI**：敌人会随机移动并朝玩家方向射击
- **视觉特效**：爆炸粒子、屏幕震动、无敌闪烁、移动烟尘
- **渐变难度**：每关敌人数量增多，移动速度加快

## 🕹️ 操作方式

| 按键 | 功能 |
|------|------|
| `W A S D` 或 `↑ ← ↓ →` | 移动坦克 |
| `J` 或 `空格` | 发射子弹 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## 🚀 快速开始

1. 克隆仓库：
   ```bash
   git clone https://github.com/YOUR_USERNAME/tank-battle.git
   ```

2. 直接用浏览器打开 `index.html` 即可游玩！

或者直接访问 GitHub Pages：`https://YOUR_USERNAME.github.io/tank-battle/`
